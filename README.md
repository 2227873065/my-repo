# 蓝绿发布演示项目

## 版本说明

- **main 分支** = v1 旧版本
- **v2 分支** = v2 新版本

## 接口

| 接口 | v1 | v2 |
|------|----|----|
| `/health` | ✅ | ✅ |
| `/api/version` | v1 | v2 |
| `/api/info` | ✅ | ✅ |
| `/api/users` | ❌ | ✅（新增） |

## 演示流程

1. 部署 main 分支（v1）→ 访问 `/api/version` 显示"旧版本运行中"
2. 部署 v2 分支（v2）→ 流量自动切换 → 显示"新版本运行中"
3. 点击回滚 → 流量切回 v1 → 又显示"旧版本运行中"

访问地址不变，完美演示蓝绿发布和版本控制。
